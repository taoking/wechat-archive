# WeChat Archive v0.2.0

在 v0.1.0 的一次性完整归档基础上，本版本提升了归档查看器的可用性，并恢复了一大类此前无法识别的消息文本。

## 新增功能

- **跨会话搜索消息内容**：查看器工具栏新增搜索入口，可在所有会话中搜索消息文本（此前只能搜索会话标题）。点击搜索结果会自动切换会话并跳转、高亮到对应消息。
- **归档恢复统计**：查看器新增统计面板，展示消息按类型（文本/图片/视频/语音/未识别）的分布，以及媒体按恢复状态的分布，帮助了解一份归档的可读比例。
- **恢复更多消息文本**：部分较新微信版本会把撤回通知、位置分享、链接/小程序/引用回复等消息正文压缩存储。安装本机 `zstd`（`brew bundle` 已包含）后，完整导出会自动尝试解压并归一化为可读文本；未安装 `zstd` 时，这些消息仍按原始 SQLite 值无损保留，只是继续显示为未识别消息。在一份约 5.4 万条消息的真实归档上验证，此前 21.5% 的未识别消息降到约 8%。
- 消息图片/视频缩略图现在会被缓存，减少会话滚动时的重复解码。

## 修复

- 完整导出失败时，此前会统一提示"目标目录仅保留用于验证，请使用新的空目录重试"，即使真正原因与目录是否为空无关（最常见的是归档目标目录嵌套在普通 SQLite 目录或账号目录内部）。现在会针对已知原因给出更具体的提示。

## 隐私

- 与 v0.1.0 相同：所有处理均在本机完成，不上传聊天数据或密钥。新增的消息搜索只查询已导入归档内的字段，不会读取或上传源数据库、微信目录或密钥。

## 依赖变化

- `Brewfile` 新增 `zstd`（用于解压部分压缩存储的消息正文）。Apple 系统 `Compression` 框架不支持 Zstandard，因此这里沿用了 Silk 语音解码器已有的"可选本机 CLI 工具"边界：未安装 `zstd` 时相关消息保持未识别，不影响归档其余部分，也不会导致导出失败。发行版 `.app` 目前尚未内置 `zstd`（与 Silk 解码器现状相同）。

## 分发

- macOS Apple Silicon App 内置 SQLCipher 和所需的 OpenSSL runtime，第三方许可证位于 App bundle 内。
- 签名：AD-HOC。
- Notarization：尚未完成。
- 由于构建尚未 notarize，macOS 首次启动时可能显示安全警告。
