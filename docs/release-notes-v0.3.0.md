# WeChat Archive v0.3.0

在 v0.2.0 的基础上大幅提升了归档查看器的浏览体验：派生搜索索引、按日期跳转、双向游标分页、右键操作与快捷键，以及更可靠的引用消息展示。

## 新增功能

- **派生 FTS 搜索索引**：首次打开归档时，会在本机 Application Support 下建立一个可随时删除、可自动重建的私有全文搜索索引（目录 `0700`、文件 `0600`），只包含显示搜索所需的消息文本字段，不含来源数据库、原始行或密钥。索引不可用（尚未建好、被取消、当前 SQLite 不支持 FTS，或索引文件损坏）时会自动回退到只读 `LIKE` 搜索，不影响正常使用。
- **按日期跳转**：新增日历入口，可按当前会话中实际有消息的年份/月份浏览，点击日期即可跳转到当天第一条消息附近。
- **双向游标分页**：搜索或日期跳转后，时间线支持同时向更早和更新方向继续加载，使用稳定游标避免相同时间戳导致的重复或遗漏。
- **右键菜单与快捷键**：文本消息可复制；图片、视频、语音可另存或在 Finder 中显示；`⌘F` 全局搜索、`⌘E` 导出当前会话、`⌘J` 回到最新消息。
- **引用消息渲染优化**：微信的引用/回复消息不再原样显示内部 XML，而是解析为"引用「发送者」：摘要 + 回复正文"的可读格式。

## 修复

- 引用消息解析对回复正文中恰好包含 XML 收尾标签片段（如 `</msg>`）的极端情况做了修正，避免这部分正文被误判并截断。
- 派生搜索索引文件损坏时，不再需要手动删除——重新索引会自动检测并重建，不会一直卡在只读 LIKE 回退模式。
- 消除了搜索索引路径在后台线程写入、主线程读取之间的一处数据竞争。
- 侧边栏会话右键菜单的"打开"项此前点击无效，现已修复。
- 群聊中对自己发送的消息不再提供"复制文字、发送者和时间"（此前会复制出占位符而非真实发送者名）。

## 性能

- 消息跳转不再重复做一次多余的全表位置扫描。
- 搜索结果列表的头像改为按结果集批量解析一次，不再每次界面刷新都重新查询。

## 隐私

- 与此前版本一致：所有处理均在本机完成。新增的派生搜索索引同样只保存在本机私有目录，不上传，且可随时删除。

## 分发

- macOS Apple Silicon App 内置 SQLCipher 和所需的 OpenSSL runtime，第三方许可证位于 App bundle 内。
- 签名：AD-HOC。
- Notarization：尚未完成。
- 由于构建尚未 notarize，macOS 首次启动时可能显示安全警告。
